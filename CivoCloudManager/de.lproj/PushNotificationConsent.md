## 1. WORUM DIE APP BITTET

Beim ersten Start der App fragt macOS, ob Civo Cloud Manager Mitteilungen anzeigen und Töne abspielen darf. Die App fragt nur nach dieser Berechtigung. Sie nutzt sie, um auf Ihrem Mac eine lokale Benachrichtigung anzuzeigen, zum Beispiel wenn ein Pod eines Kubernetes-Clusters, mit dem Sie verbunden sind, neu gestartet wurde.

## 2. WAS DIE APP NICHT TUT

- Sie verwendet keine Remote-Push-Benachrichtigungen. Von einem Server wird nichts an Ihren Mac gesendet.
- Sie nutzt weder den Apple Push Notification service (APNs) noch Firebase Cloud Messaging (FCM) und registriert und speichert kein Push-Token.
- Sie sendet keine Marketing-Benachrichtigungen.
- Sie wird nicht für iOS oder Android vertrieben.

Die Benachrichtigungen werden auf Ihrem Mac erzeugt, aus Daten, die die App bereits von den von Ihnen verbundenen Diensten erhalten hat. Sie werden nicht an uns gesendet, und wir erhalten sie nicht.

## 3. SO ÄNDERN SIE IHRE ENTSCHEIDUNG

Sie können Benachrichtigungen jederzeit in den Systemeinstellungen unter Mitteilungen erlauben oder beenden, indem Sie Civo Cloud Manager auswählen. Wenn Sie Benachrichtigungen nicht erlauben, funktioniert die App wie bisher und zeigt keine Mitteilungen an.
