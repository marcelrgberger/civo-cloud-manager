## 1. QUÉ SOLICITA LA APLICACIÓN

La primera vez que se ejecuta la aplicación, macOS pregunta si Civo Cloud Manager puede mostrar alertas y reproducir sonidos. La aplicación solicita únicamente este permiso. Lo utiliza para mostrar una notificación local en su Mac, por ejemplo cuando se ha reiniciado un pod de un clúster de Kubernetes al que usted está conectado.

## 2. QUÉ NO HACE LA APLICACIÓN

- No utiliza notificaciones push remotas. No se envía nada a su Mac desde un servidor.
- No utiliza el Apple Push Notification service (APNs) ni Firebase Cloud Messaging (FCM), y no registra ni almacena ningún token push.
- No envía notificaciones de marketing.
- No se distribuye para iOS ni para Android.

Las notificaciones se crean en su Mac, a partir de datos que la aplicación ya ha recibido de los servicios a los que usted se conectó. No se nos envían y nosotros no las recibimos.

## 3. CÓMO CAMBIAR SU ELECCIÓN

Puede permitir o detener las notificaciones en cualquier momento en Ajustes del Sistema, en Notificaciones, seleccionando Civo Cloud Manager. Si no permite las notificaciones, la aplicación funciona como antes y no muestra alertas.

## 4. MÁS INFORMACIÓN Y CONTACTO

La forma en que la aplicación trata los datos se describe en la [Política de Privacidad](PrivacyPolicy.md). Para preguntas sobre este aviso, escriba a hello@digitalfreedom.co.za. Las solicitudes de protección de datos se dirigen a data-protection@digitalfreedom.co.za.
