## 1. APA YANG DIMINTA OLEH APLIKASI

Saat aplikasi dijalankan untuk pertama kalinya, macOS menanyakan apakah Civo Cloud Manager boleh menampilkan peringatan dan memutar suara. Aplikasi hanya meminta izin ini. Izin tersebut digunakan untuk menampilkan notifikasi lokal di Mac Anda, misalnya ketika sebuah pod dari klaster Kubernetes yang terhubung dengan Anda telah dimulai ulang.

## 2. APA YANG TIDAK DILAKUKAN OLEH APLIKASI

- Aplikasi tidak menggunakan notifikasi push jarak jauh. Tidak ada yang dikirim dari server ke Mac Anda.
- Aplikasi tidak menggunakan Apple Push Notification service (APNs) maupun Firebase Cloud Messaging (FCM), dan tidak mendaftarkan atau menyimpan token push.
- Aplikasi tidak mengirim notifikasi pemasaran.
- Aplikasi tidak didistribusikan untuk iOS atau Android.

Notifikasi dibuat di Mac Anda, dari data yang telah diterima aplikasi dari layanan yang Anda hubungkan. Notifikasi tersebut tidak dikirim kepada kami, dan kami tidak menerimanya.

## 3. CARA MENGUBAH PILIHAN ANDA

Anda dapat mengizinkan atau menghentikan notifikasi kapan saja di Pengaturan Sistem, pada Notifikasi, dengan memilih Civo Cloud Manager. Jika Anda tidak mengizinkan notifikasi, aplikasi tetap berfungsi seperti biasa dan tidak menampilkan peringatan.
