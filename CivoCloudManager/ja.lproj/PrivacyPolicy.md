## 1. はじめに

本プライバシーポリシーは、お客様が当社のアプリケーション、ソフトウェア、ウェブサイトおよび関連サービス（以下「本サービス」）をご利用になる際に、DigitalFreedom（DigitalFreedom Global LLC のブランド。以下総称して「当社」）がお客様の個人データをどのように収集、利用、保存および保護するかを説明するものです。本書は macOS アプリ Civo Cloud Manager（以下「本アプリ」）に係るものです。

### 1.1 グローバルな適用範囲

本アプリは Apple App Store を通じて配信されるため、App Store がサービスを提供するすべての国および地域で入手できます。本プライバシーポリシーは、本アプリをダウンロード、アクセスまたは利用する国にかかわらず、本アプリのすべての利用者に世界的に適用されます。

### 1.2 世界共通の基準としての GDPR

当社は、**欧州連合一般データ保護規則（GDPR）** および関連する EU データ保護法を基準として採用し、これを**世界共通の最低基準**として適用します。すなわち、あらゆる国のすべての利用者が、本ポリシーに定める少なくとも GDPR 水準の保護を受けます。当社はさらに、利用者の管轄地域で適用される現地のデータ保護法を尊重して遵守し、当該現地法が利用者にとってより保護的である場合には、より保護的な基準を適用します。

当社は、お客様のプライバシーを保護し、次の法令を含む（ただしこれらに限られない）適用されるデータ保護法令を遵守することを約束します。

- EU 一般データ保護規則（GDPR）— 世界共通の基準として適用
- ドイツ連邦データ保護法（BDSG）
- 英国一般データ保護規則（UK GDPR）および 2018年データ保護法
- スイス連邦データ保護法（FADP）
- カリフォルニア州消費者プライバシー法（CCPA）／カリフォルニア州プライバシー権法（CPRA）およびその他の米国の州プライバシー法
- カナダ個人情報保護及び電子文書法（PIPEDA）
- オーストラリア 1988年プライバシー法
- ブラジル一般データ保護法（LGPD）
- 日本の個人情報の保護に関する法律（APPI）
- 韓国個人情報保護法（PIPA）
- インドのデジタル個人データ保護法（DPDP 法）および IT 法
- 南アフリカ個人情報保護法（POPIA）
- 本サービスが Apple App Store を通じて提供されている管轄地域における、その他すべての適用される国内データ保護制度

### 1.3 本アプリがお客様のデータをどのように取り扱うか

Civo Cloud Manager は、お客様の Mac から Civo クラウドアカウントを管理するアプリです。ユーザーアカウント、アナリティクス、クラッシュレポート、広告、トラッキングは一切ありません。

- 発行者は、本アプリのクラウド管理機能でお客様が管理するデータを受信するバックエンドを運営していません。お客様の Civo API キー、本アプリの設定およびリクエストの内容は、お客様の Mac 上にとどまるか、お客様が本アプリの利用によって選択した受信者に送信されます（第 6.1 項）。

## 3. 当社が収集するデータ

### 3.1 お客様が提供するデータ

- **サポートリクエスト。** サポートタブをご利用の際、サポートポータルが収集するのは、お客様が入力した内容のみです。すなわち、お客様の氏名、メールアドレスおよび問題の説明です。また、メッセージの件名、添付ファイル、およびお客様が任意でお知らせくださるアカウント関連の情報も受け取ります。セキュリティ脆弱性を報告するための別の経路をご利用の場合は、脆弱性の詳細とお客様の連絡先を受け取ります。当社は、これらをお客様のリクエストの処理のためにのみ利用します。
- **クラウド管理データ。** お客様の Civo API キー、本アプリで行う設定および管理するリソースは、当社には提供されません。これらはお客様の Mac 上にとどまるか、第 6.1 項に記載する受信者に送信されます。

### 3.2 自動的に収集されるデータ

- **サポートタブ。** ポータルが利用されると、そのウェブサーバーは、お客様の IP アドレス、時刻、リクエストされたページ、参照元ページおよびブラウザーのユーザーエージェントを記録します。ポータルは、フォームの入力中にフォームの安全を保つための、セッション Cookie を一つ設定します。この Cookie は二時間で失効します。入力中は、お客様の氏名、メールアドレスおよびメッセージの下書きが、お客様の端末上の埋め込みブラウザーのローカルストレージに保持されることがあります。この下書きは、フォームを送信すると削除されます。
- **お客様の Mac に保存され、当社が受け取らないもの。** お客様の Civo API キー（macOS キーチェーン）、保存されたインスタンスの認証情報（この Mac のデータ保護キーチェーン。同期されず、読み取りにはユーザーの在席確認が必要）、暗号化された SSH 鍵のバックアップとそのマスターキー（アプリケーションサポートフォルダとキーチェーン）、選択したリージョン、管理対象のファイアウォール設定、IP プリセット、ログイン時の起動設定とオンボーディング設定、および七日間のトライアルの開始日（ユーザーデフォルト）、時間指定のファイアウォール閉鎖設定と完了した月の請求額のキャッシュ（アプリケーションサポートフォルダ）、ならびに本アプリでのお客様の操作のアクティビティログ（リソースの種類、名称、識別子、操作および短い詳細。キー、ヘッダー、生の応答は含まない）です。アクティビティログは最新の 200 件を保持し、それより古いものは破棄されます。このログは、お客様が本アプリのデータを削除するまで、お客様の Mac 上にとどまります。
- **システムログ。** 本アプリは macOS の統合ログに書き込みます。エントリーはオペレーティングシステムによって管理され、本アプリがアップロードすることはありません。

### 3.3 お客様の指示により第三者と交換されるデータ

- **Civo。** 本アプリは、認証としてお客様の Civo API キーを含むリクエストを Civo API（api.civo.com）に送信し、インスタンスコンソールについては Civo のコンソールホストに送信します。これらのリクエストは当社ではなく、Civo に直接届きます。
- **お客様自身のエンドポイント。** 本アプリは、お客様のクラスターの kubeconfig に記載された Kubernetes API サーバーにそこに含まれるクライアント証明書を用いて接続し、またオブジェクトストアの S3 互換エンドポイントにそのアクセスキーとシークレットキーを用いて接続します。本アプリは、kubeconfig の認証情報そのものを保存しません。
- **公開 IP の照会。** ファイアウォール機能のため、本アプリは ipify（api.ipify.org）、ifconfig.me、icanhazip.com に、この順にフォールバックしながら、お客様の公開 IP アドレスを問い合わせます。これらのサービスは、一般のウェブサーバーと同様に、お客様の IP アドレスを認識します。
- **Apple。** Full Access の購入および七日間のトライアルの権利は、StoreKit を通じて Apple が取り扱います。当社は支払いデータを一切受け取りません。このデータには Apple 自身のプライバシーポリシーが適用されます（第 6.1.2 項）。
- **リンク。** digitalfreedom.co.za や civo.com などのウェブサイトへのリンクは、お客様のブラウザーで開きます。

### 3.4 センサー、デバイスおよび生体データ

- **ユーザーの在席確認（Face ID / Touch ID / パスワード）：** 保存された認証情報のロック解除に使用します。生体テンプレートがお客様の端末の外に出ることはありません。本アプリがオペレーティングシステムから受け取るのは、可否の結果のみです。
- **通知：** 本アプリは、アラートの表示とサウンドの再生の許可を macOS に求め、お客様の Mac 上でローカルに通知をスケジュールします。プッシュトークンは登録せず、リモート通知も受信しません。
- **お客様が選択するファイル：** SSH 秘密鍵、kubeconfig ファイル、およびお客様がエクスポートしたオブジェクトストアのダウンロードは、お客様がシステムのファイルダイアログで指定した場所に書き込まれます。これらのコピーは本アプリの保護および管理の範囲外にあり、本アプリはこれらを追跡、暗号化、削除しません。

### 3.5 収集しないデータ

本アプリは、次のものを収集または利用**しません**。

- 位置情報、カメラ、マイク、連絡先、カレンダー、写真またはヘルスケアのデータ
- アナリティクス、クラッシュレポートまたはテレメトリ
- 広告識別子、または他社のアプリやウェブサイトをまたいでお客様を追跡するためのデータ
- 支払いカードのデータ（支払いは Apple が収集し、当社がカードの詳細を受け取ることはありません）

## 8. データの保存期間

当社は、本ポリシーに記載した目的に必要な期間に限り、個人データを保存します。

## 9. データセキュリティ

完全に安全なシステムは存在しません。当社は、絶対的なデータセキュリティを保証することはできません。

### 17.10 韓国（PIPA）

- **国外への移転：** 個人情報を国外へ移転するには、**移転を受ける者、移転先の国、移転の日時および方法、移転する項目、受領者の利用目的および保有期間**を通知し、お客様の個別の同意を得る必要があります。サポートリクエストについては、受領者と国は § 6.1.1 および § 7 に、項目はお客様の氏名、メールアドレスおよびメッセージ、目的はリクエストの処理、保有期間は § 8 に記載しています。
