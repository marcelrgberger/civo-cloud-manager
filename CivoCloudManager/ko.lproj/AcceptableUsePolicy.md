## 1. 서론

이 허용 사용 정책("AUP")은 DigitalFreedom Global LLC의 브랜드인 DigitalFreedom(이하 "제공자")가 제공하는 모든 애플리케이션, 소프트웨어, 웹사이트, API 및 관련 서비스(이하 "서비스")의 사용에 적용됩니다.

이 AUP는 당사의 [서비스 약관](TERMS_OF_SERVICE.md), [최종 사용자 사용권 계약](EULA.md), [공정 사용 정책](FAIR_USE_POLICY.md)을 보완합니다. 상충되는 경우, 더 엄격한 조항이 우선 적용됩니다.

서비스를 이용함으로써 귀하는 본 AUP를 준수할 것에 동의합니다. 위반 시 접근이 중단되거나 해지될 수 있습니다.

### 1.1 글로벌 적용 범위

서비스는 Apple App Store와 Google Play Store를 통해 배포되며, 해당 플랫폼이 제공되는 모든 국가 및 지역에서 이용할 수 있습니다. 이 AUP는 전 세계 모든 사용자에게 적용됩니다. 제공자는 유럽연합 일반 데이터 보호 규정(GDPR) 및 관련 EU 법률을 기본 기준으로 채택하며, 이를 전 세계적으로 최소한의 기준으로 적용합니다. 사용자의 관할 지역에서 더 보호적인 현지 법률이 있는 경우 추가로 적용됩니다.

## 2. 일반 원칙

귀하는 서비스를 다음과 같이 사용해야 합니다:

- 모든 관련 법률 및 규정을 준수하여 합법적으로 사용
- 타인에게 해를 끼치지 않는 책임 있는 방식으로 사용
- 서비스의 본래 목적에 따라 사용
- 제삼자의 권리를 침해하지 않고 사용

## 3. 금지 행위

### 3.1 불법 행위

귀하는 서비스를 다음과 같은 목적으로 사용할 수 없습니다:

- 어떤 관할권에서든 적용 가능한 법률, 법령, 규정 또는 조례를 위반하는 행위
- 범죄 행위를 촉진, 조장 또는 참여하는 행위
- 자금 세탁 또는 테러 자금 조달 행위
- 수출 통제 또는 제재법(유럽연합, 미국 OFAC, 유엔 제재 포함) 위반
- 반부패 또는 반뇌물 법률(영국 Bribery Act, 미국 FCPA, 독일 StGB §§ 299 ff. 포함) 위반

### 3.2 유해한 콘텐츠

귀하는 다음과 같은 콘텐츠를 생성, 저장, 전송 또는 배포하는 데 서비스를 사용할 수 없습니다:

- 인종, 민족, 종교, 성별, 성적 지향, 장애 또는 기타 보호 대상 특성을 근거로 폭력, 증오 또는 차별을 조장하는 콘텐츠
- 아동 성적 학대 자료(CSAM) 또는 미성년자를 착취하는 콘텐츠
- 테러 또는 폭력적 극단주의를 선동하는 콘텐츠
- 명예훼손, 괴롭힘, 위협 또는 협박성 콘텐츠
- 비동의적 친밀 이미지
- 해를 끼칠 목적으로 고의적으로 오도하거나 허위 정보를 유포하는 콘텐츠

### 3.3 지적 재산권 침해

귀하는 다음과 같은 행위를 할 수 없습니다:

- 저작권, 상표, 특허, 영업비밀 또는 기타 지적 재산권을 침해하는 행위
- 불법 복제 소프트웨어, 미디어 또는 기타 저작권 보호 자료 배포
- 디지털 권리 관리(DRM) 또는 기술적 보호 조치 우회
- 서비스를 위조품 유통에 이용하는 행위

### 3.4 보안 위반

귀하는 다음과 같은 행위를 할 수 없습니다:

- 서비스, 계정 또는 시스템에 무단으로 접근을 시도하는 행위
- 악성코드, 바이러스, 랜섬웨어 또는 기타 악의적인 코드를 전송하는 행위
- 서비스 거부(DoS/DDoS) 공격을 수행하는 행위
- 서면 허가 없이 포트 스캐닝, 취약점 스캐닝 또는 침투 테스트를 수행하는 행위
- 허가 없이 통신을 가로채거나 모니터링하는 행위
- 서비스의 취약점을 악용하는 행위(대신 책임 있는 공개를 통해 신고해야 함)

### 3.5 스팸 및 남용

다음 행위를 해서는 안 됩니다:

- 원치 않는 대량 메시지(스팸)를 발송하는 행위
- 피싱, 사회공학, 신원 사기를 행하는 행위
- 허위 계정을 생성하거나 타인을 사칭하는 행위
- 서비스 약관을 위반하여 봇, 스크레이퍼 또는 자동화 도구를 사용하는 행위
- 평점, 리뷰 또는 피드백 시스템을 조작하는 행위

### 3.6 네트워크 및 자원 남용

다음 행위를 해서는 안 됩니다:

- 타 사용자에게 성능 저하를 유발하는 방식으로 서비스를 이용하는 행위
- [공정 사용 정책](FAIR_USE_POLICY.md)에 명시된 공정 사용 범위를 초과하여 과도한 자원(대역폭, 저장소, 연산)을 소비하는 행위
- 허가 없이 암호화폐 채굴을 위해 서비스를 이용하는 행위
- 서비스를 통해 오픈 프록시, 릴레이 또는 익명화 서비스를 운영하는 행위

자원 소비, 비정상적 사용 패턴 및 추정되는 오용에 관한 세부 사항은 [공정 사용 정책](FAIR_USE_POLICY.md)에 명시되어 있으며, 제공자는 위반에 대한 결정적 증거 없이도 선의의 의심이 있을 경우 트래픽 제한, 속도 제한, 기능 제한 또는 접근 중단 조치를 취할 수 있습니다.

### 3.6.1 등급별 정량적 제한

Civo Cloud Manager는 애플리케이션 내에서 등급별 정량적 제한을 시행하지 않습니다. 애플리케이션은 타사 API(Civo REST API, 사용자의 자체 클러스터의 Kubernetes API, 사용자의 자체 오브젝트 스토어의 S3-호환 오브젝트 스토리지)에 직접 연결되며, 모든 사용은 해당 제공자의 자체 속도 제한, 할당량 및 서비스 약관이 적용됩니다.

| 요금제 / 등급 | API 요청 | 저장소 | 대역폭 | AI 호출 | 동시 세션 |
|---|---|---|---|---|---|
| 무료(메뉴바 방화벽 관리) | Civo API 제한 적용 | 제공자 미호스팅 | 제공자 미호스팅 | 해당 없음 | 해당 없음 |
| 전체 액세스(일회성 인앱 구매) | Civo API 제한 적용 | 제공자 미호스팅 | 제공자 미호스팅 | 해당 없음 | 해당 없음 |

### 3.7 프라이버시 침해

다음 행위를 해서는 안 됩니다:

- 관련 데이터 보호법을 위반하여 개인정보를 수집, 처리 또는 저장하는 행위
- 적법한 근거 없이 개인을 감시하거나 추적하는 행위
- 타인의 동의 없이 개인정보를 공개하거나 도킹하는 행위
- 미성년자의 프라이버시 권리를 침해하는 행위

## 4. 콘텐츠 기준

### 4.1 사용자 생성 콘텐츠

서비스가 사용자 생성 콘텐츠를 허용하는 경우, 귀하는 귀하가 생성, 업로드 또는 공유하는 콘텐츠에 대해 전적으로 책임을 집니다.

### 4.2 콘텐츠 심사

제공자는 다음과 같은 권리를 보유합니다:

- 본 AUP 준수 여부를 위해 콘텐츠를 검토할 권리
- 본 AUP를 위반하는 콘텐츠를 삭제하거나 접근을 차단할 권리
- 불법 콘텐츠를 법 집행기관에 신고할 권리

### 4.3 법적 의무

콘텐츠 심사는 다음을 준수합니다:

- EU 디지털 서비스법(DSA) — 규정(EU) 2022/2065
- 독일 네트워크 집행법(NetzDG)
- 영국 온라인 안전법 2023
- 전 세계적으로 적용되는 통지 및 삭제 절차

## 7. 지역별 고려사항

### 7.1 유럽 연합

- 콘텐츠 의무는 디지털 서비스법(DSA)을 준수합니다
- 투명성 보고 의무를 이행합니다
- 해당되는 경우 신뢰받는 신고자 메커니즘을 지원합니다

### 7.2 독일

- 콘텐츠 삭제에 관한 NetzDG 요건을 준수합니다
- Telemediengesetz(TMG) / Digitale-Dienste-Gesetz(DDG) 의무가 적용됩니다

### 7.3 미국

- 해당되는 경우 DMCA 세이프 하버 조항이 적용됩니다
- 통신품위법 제230조가 중개자 책임을 규율합니다
- 보안 관련 조항에 대해 CFAA 준수가 요구됩니다

### 7.4 영국

- 온라인 안전법 2023 요건을 준수합니다
- 사용자 간 및 검색 서비스에 대한 콘텐츠 조정 의무가 적용됩니다

### 7.5 호주

- 온라인 안전법 2021 요건을 준수합니다
- eSafety 위원회 신고 의무가 적용됩니다

### 7.6 캐나다

- 캐나다 콘텐츠 규제 요건을 준수합니다
- 주 소비자 보호법이 적용됩니다

### 7.7 일본

- 특정 전기통신 서비스 제공자 손해배상책임제한법이 적용됩니다
- 제공자 책임 제한법 의무를 준수합니다

### 7.8 대한민국

- 정보통신망법 요건이 적용됩니다
- 방송통신심의위원회 지침을 준수합니다

### 7.9 인도

- 정보기술(중개자 지침 및 디지털 미디어 윤리 강령) 규칙, 2021이 적용됩니다
- 콘텐츠 심사 및 불만 처리 절차를 유지합니다

### 7.10 브라질

- 인터넷 민사법(Marco Civil da Internet, 법률 번호 12.965/2014) 요건이 적용됩니다
- 사법적 통지 및 삭제 의무를 준수합니다

### 7.11 기타 관할권

- 서비스가 제공되는 모든 관할권에서 제공자는 해당 콘텐츠 규제, 중개자 책임, 소비자 보호법을 준수합니다
