## 1. 서론

본 개인정보 처리방침은 DigitalFreedom(DigitalFreedom Global LLC의 브랜드, 이하 "당사", "저희", "우리")가 귀하가 당사의 애플리케이션, 소프트웨어, 웹사이트 및 관련 서비스(이하 "서비스")를 이용할 때 귀하의 개인정보를 수집, 이용, 보관 및 보호하는 방법을 설명합니다.

### 1.1 글로벌 적용 범위

당사 애플리케이션은 Apple App Store 및 Google Play Store를 통해 배포되며, 해당 플랫폼이 제공되는 모든 국가 및 지역에서 이용 가능합니다. 본 개인정보 처리방침은 서비스가 다운로드, 접근 또는 사용되는 국가와 관계없이 모든 서비스 이용자에게 전 세계적으로 적용됩니다.

### 1.2 GDPR의 글로벌 기준 적용

당사는 **유럽연합 일반개인정보보호법(GDPR)** 및 관련 EU 데이터 보호법을 가장 엄격한 기준으로 삼아 **글로벌 최저선**으로 적용합니다. 모든 사용자는 본 정책에 명시된 GDPR 수준 이상의 보호를 받습니다. 또한, 사용자의 관할지에서 적용되는 현지 데이터 보호법도 존중 및 준수하며, 현지 법이 더 높은 보호를 제공하는 경우 해당 기준을 우선 적용합니다.

당사는 귀하의 개인정보 보호와 관련 법령 준수를 위해 다음을 포함하되 이에 국한되지 않는 데이터 보호법을 준수할 것을 약속합니다:

## 3. 수집하는 데이터

### 3.1 귀하가 제공하는 데이터

- 계정 정보(이름, 이메일 주소, 사용자명)
- 커뮤니케이션 데이터(지원 요청, 피드백)
- 결제 정보(제삼자 결제 제공업체를 통해 처리)
- 사용자가 생성한 콘텐츠

### 3.2 자동으로 수집되는 데이터

- 기기 정보 (기기 종류, 운영 체제, 버전)
- 사용 데이터 (사용한 기능, 상호작용 패턴)
- 로그 데이터 (IP 주소, 접속 시간, 오류 로그)
- 분석 데이터 (집계된 사용 통계)

### 3.3 제삼자로부터 수집하는 데이터

- 소셜 로그인 제공업체로부터의 인증 데이터 (해당되는 경우)
- 앱 스토어(Apple, Google)에서 제공하는 플랫폼별 데이터

### 3.4 센서, 기기 및 생체 데이터

앱이 기기의 센서 또는 생체 인식을 사용하는 경우:

- **생체 인증** (Face ID / Touch ID / Android BiometricPrompt): 생체 정보 템플릿은 절대 기기를 벗어나지 않습니다. 앱은 운영 체제로부터 예/아니오 결과만 받습니다.
- **카메라, 마이크, 위치, 사진, 연락처, 캘린더, 동작, 건강**: 해당 기능을 직접 사용할 때만 접근합니다. 각 접근 시 운영 체제가 저희의 사용 설명 문구와 함께 접근 허용을 요청합니다.
- **건강 및 피트니스 데이터** (HealthKit / Health Connect): 사용자가 선택한 특정 기능을 위해서만 처리하며, 광고 목적으로 제삼자와 공유하지 않고, AI 모델 학습에도 사용하지 않습니다.
- **앱 추적 투명성(iOS) / AAID 제어(Android)**: 기본적으로 DigitalFreedom 앱은 타사 앱 및 웹사이트에서 사용자를 추적하지 않습니다. 특정 기능에 필요하지 않는 한 ATT 요청을 표시하지 않으며, 향후 기능에서 필요할 경우에도 거부해도 앱의 나머지 기능 이용에 제한이 없습니다.

### 3.5 수집하지 않는 데이터

앱별 부속서에서 특정 기능에 대해 명시적으로 고지하지 않는 한, 다음 정보를 **수집하지 않습니다**:

- 백그라운드에서의 정확한 위치 정보
- 연락처 / 주소록
- 기기에서의 SMS / 이메일 내용
- 앱 외부의 인터넷 검색 기록
- 행동 기반 광고 식별자
- 결제 카드 정보 (인앱 구매의 경우 Apple 및 Google이 판매자임)

- 법적 의무(예: 독일법상 세무 보관 기간: 최대 10년)
- 정당한 이익(예: 분쟁 해결 등)

보관 기간 만료 시 데이터는 안전하게 삭제되거나 익명화됩니다.

## 9. 데이터 보안

당사는 귀하의 데이터를 보호하기 위해 다음을 포함한 적절한 기술적·관리적 조치를 시행합니다:

- 전송 중 암호화(TLS 1.3) 및 저장 시 암호화(AES-256 또는 동등 수준)
- 접근 통제(RBAC, 관리자 접근 시 MFA, 최소 권한 원칙)
- 정기적인 보안 평가 및 하위 처리자 감사
- 승인된 인원에 한정된 감사 로그
- 오프사이트 복제본을 포함한 일일 백업
- 내부 침해 대응 계획(Art. 33/34 GDPR)에 따른 문서화된 사고 대응

어떠한 시스템도 완전히 안전하지 않습니다. 당사는 절대적인 데이터 보안을 보장할 수 없습니다.

### 9.1 귀하에 대한 침해 통지

개인 데이터 침해가 귀하의 권리와 자유에 **높은 위험을 초래할 가능성이 있는 경우**(GDPR 제 34 조), 귀하의 계정에 연결된 이메일 주소를 통해 지체 없이 귀하에게 다음 사항을 포함하여 통지합니다:

- 침해의 성격
- 관련된 기록의 범주 및 대략적인 수
- 예상되는 결과
- 침해에 대응하고 부정적 영향을 완화하기 위해 취한 또는 제안된 조치
- 추가 정보를 위한 연락처

개별 통지가 과도한 노력을 요구하는 경우, https://digitalfreedom.co.za/. 에서 공개적으로 공지합니다.

## 10. 귀하의 권리

### 10.1 GDPR(유럽연합/유럽경제지역/영국)상의 권리

귀하는 다음과 같은 권리가 있습니다:

- 귀하의 개인정보에 대한 **접근**(GDPR 제 15 조)
- 부정확한 데이터의 **정정**(GDPR 제 16 조)
- 귀하의 데이터 **삭제**("잊혀질 권리") (GDPR 제 17 조)
- 처리의 **제한**(GDPR 제 18 조)
- **데이터 이동권**(GDPR 제 20 조)
- 처리에 대한 **반대**(GDPR 제 21 조)
- 언제든지 **동의 철회**(GDPR 제 7(3) 조)
- 감독기관에 **불만 제기**

### 10.2 CCPA/CPRA(캘리포니아)상의 권리

캘리포니아 거주자는 다음과 같은 권리가 있습니다:

- 수집되는 개인정보에 대해 알 권리
- 개인정보 삭제 요청권
- 개인정보의 판매 또는 공유 거부권
- 프라이버시 권리 행사에 따른 차별 금지
- 부정확한 개인정보의 정정 요청권
- 민감한 개인정보 사용 제한권

### 10.3 PIPEDA(캐나다)상의 권리

캐나다 거주자는 다음과 같은 권리가 있습니다:

- 자신의 개인정보에 접근할 권리
- 정보의 정확성에 이의를 제기할 권리
- (법적 또는 계약상 제한이 있는 경우를 제외하고) 동의 철회권

### 10.4 호주 프라이버시법상의 권리

호주 거주자는 다음과 같은 권리가 있습니다:

- 자신의 개인정보에 접근할 권리
- 부정확한 정보의 정정 요청권
- 호주 정보위원회(OAIC)에 불만 제기권

### 10.5 LGPD(브라질)상의 권리

브라질 거주자는 다음과 같은 권리가 있습니다:

- 데이터 처리 확인
- 데이터 접근
- 불완전하거나 부정확한 데이터의 정정
- 불필요한 데이터의 익명화, 차단 또는 삭제
- 데이터 이동권
- 공유된 데이터에 대한 정보
- 동의 철회권

## 13. 자동 의사결정 및 AI

### 13.1 법적 또는 유사하게 중대한 영향을 미치는 자동화된 결정

당사는 다음의 경우를 제외하고 귀하에게 법적 효력을 발생시키는 자동화된 의사결정 또는 프로파일링을 수행하지 않습니다:

- 귀하가 명시적으로 동의한 경우
- 계약 이행에 필수적인 경우
- 관련 법률에 의해 허용된 경우

이러한 처리가 이루어지는 경우, 귀하는 GDPR 제22조(3항)에 따라 인간의 개입을 받을 권리, 의견을 제시할 권리, 결정을 이의제기할 권리를 가집니다.

### 13.2 AI 지원 기능

서비스에 AI 지원 기능(예: OpenAI 등 타사 AI API를 통한 콘텐츠 생성, 요약, 분류)이 포함된 경우, [AI 투명성 고지](AI_TRANSPARENCY_NOTICE.md)에서 다음을 설명합니다:

- 어떤 기능이 AI를 사용하는지
- 어떤 AI 제공업체가 사용되는지
- AI로 전송되는 데이터
- AI 제공업체의 데이터 보관 기간(기본적으로 OpenAI API는 30일)
- 거부권
- AI 생성 콘텐츠 표시(유럽연합 AI법 제50조, 2026-08-02 발효)

### 13.3 공정 사용 정책 집행

[공정 사용 정책](FAIR_USE_POLICY.md)은 운영 텔레메트리가 남용을 탐지하고, 필요시 속도 제한, 제한 또는 일시 중지를 적용하는 방법을 설명합니다. 자동 탐지는 인간 검토를 보조하며, 공정 사용 정책에 따른 자동 결정은 즉각적인 위협을 완화하는 데 엄격히 필요한 경우를 제외하고 인간 개입 없이 귀하에게 법적 효력을 발생시키지 않습니다.

### 13.4 마케팅 커뮤니케이션

마케팅 이메일 및 마케팅 푸시 알림은 귀하의 **명시적이고 별도의 동의**가 있을 때만 발송됩니다. 귀하는 언제든지 동의를 철회할 수 있으며, 이는 서비스 이용에 영향을 미치지 않습니다.

### 13.5 계정 삭제

귀하는 언제든지 계정을 삭제하고 데이터 삭제를 요청할 수 있습니다. 앱 내, 이메일, 우편 경로에 대한 자세한 내용은 [계정 삭제 안내](ACCOUNT_DELETION_NOTICE.md)를 참조하십시오.

- 처리는 일반 데이터 보호법(LGPD)을 준수합니다
