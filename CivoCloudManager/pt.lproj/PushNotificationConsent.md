## 1. O QUE A APLICAÇÃO PEDE

Na primeira vez que a aplicação é executada, o macOS pergunta se o Civo Cloud Manager pode mostrar alertas e reproduzir sons. A aplicação pede apenas esta autorização. Utiliza-a para mostrar uma notificação local no seu Mac, por exemplo quando um pod de um cluster Kubernetes ao qual está ligado foi reiniciado.

## 2. O QUE A APLICAÇÃO NÃO FAZ

- Não utiliza notificações push remotas. Nada é enviado de um servidor para o seu Mac.
- Não utiliza o Apple Push Notification service (APNs) nem o Firebase Cloud Messaging (FCM), e não regista nem armazena nenhum token push.
- Não envia notificações de marketing.
- Não é distribuída para iOS nem para Android.

As notificações são criadas no seu Mac, a partir de dados que a aplicação já recebeu dos serviços a que se ligou. Não nos são enviadas, e nós não as recebemos.

## 3. COMO ALTERAR A SUA ESCOLHA

Pode permitir ou deixar de permitir notificações em qualquer momento em Definições do Sistema, em Notificações, selecionando o Civo Cloud Manager. Se não permitir notificações, a aplicação funciona como antes e não mostra alertas.
