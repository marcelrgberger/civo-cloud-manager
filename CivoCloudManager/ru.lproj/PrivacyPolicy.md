- Информация об аккаунте (имя, адрес электронной почты, имя пользователя)

### 3.2 Данные, собираемые автоматически

- Информация об устройстве (тип устройства, операционная система, версия)
- Данные об использовании (используемые функции, шаблоны взаимодействия)
- Журнальные данные (IP-адрес, время доступа, журналы ошибок)
- Аналитические данные (сводная статистика использования)

### 3.3 Данные от третьих лиц

- Данные аутентификации от поставщиков социальных входов (если применимо)
- Данные, специфичные для платформы, из магазинов приложений (Apple, Google)

### 3.4 Данные сенсоров, устройств и биометрии

Если приложение использует сенсоры или биометрию на вашем устройстве:

- **Биометрическая аутентификация** (Face ID / Touch ID / Android BiometricPrompt): биометрический шаблон никогда не покидает ваше устройство. Приложение получает только результат да/нет от операционной системы.
- **Камера, микрофон, местоположение, фотографии, контакты, календарь, движение, здоровье**: доступ осуществляется только при активном использовании функции, которой это необходимо. Каждый доступ сопровождается системным запросом с нашим пояснительным текстом о целях использования.
- **Данные о здоровье и фитнесе** (HealthKit / Health Connect): обрабатываются только для конкретной используемой функции; не передаются третьим лицам для рекламы; не используются для обучения ИИ-моделей.
- **App Tracking Transparency (iOS) / AAID-контроль (Android)**: по умолчанию приложения DigitalFreedom не отслеживают вас в приложениях и на сайтах других компаний. Мы не показываем запрос ATT, если только конкретная функция не требует этого; если в будущем появится такая функция, вы сможете отказаться без потери доступа к остальным возможностям приложения.

### 3.5 ДАННЫЕ, КОТОРЫЕ НЕ СОБИРАЮТСЯ

Если явно не указано для конкретной функции в дополнительном соглашении к приложению, мы **не** собираем:

- точное местоположение в фоновом режиме
- контакты / адресную книгу
- содержимое SMS / электронной почты с вашего устройства
- историю просмотров вне приложения

- Не подвергаться дискриминации за осуществление прав на конфиденциальность
- Исправлять неточную персональную информацию
- Ограничивать использование чувствительной персональной информации

### 10.3 Права по PIPEDA (Канада)

Жители Канады имеют право:

- Получать доступ к своей персональной информации
- Оспаривать точность своей информации
- Отозвать согласие (с учётом юридических или договорных ограничений)

### 10.4 Права по Австралийскому закону о конфиденциальности

Жители Австралии имеют право:

- Получать доступ к своей персональной информации
- Запрашивать исправление неточной информации
- Подавать жалобу в Управление австралийского комиссара по информации (OAIC)

### 10.5 Права по LGPD (Бразилия)

Жители Бразилии имеют право:

- Подтверждение факта обработки данных
- Доступ к данным
- Исправление неполных или неточных данных
- Анонимизация, блокировка или удаление ненужных данных
- Переносимость данных
- Получение информации о передаче данных
- Отзыв согласия
