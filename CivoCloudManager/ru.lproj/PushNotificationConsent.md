## 0. ЦЕЛЬ

Данное уведомление отображается **до** появления системного запроса разрешения на push-уведомления в iOS / Android. Оно информирует пользователя — простым языком — на что он даёт согласие. Это соответствует требованиям:

- **Ст. 6(1)(a) GDPR** — свободное, конкретное, информированное, однозначное согласие на обработку, связанную с уведомлениями, если уведомление содержит персональные данные
- **Ст. 13 GDPR** — прозрачность в момент сбора
- **Директива ePrivacy 2002/58/EC ст. 13 / национальные реализации** — для любых уведомлений с маркетинговым содержанием
- **Apple Human Interface Guidelines** и **Google Play Developer Policy** — лучшие практики предварительного информирования

Сервисы распространяются по всему миру через Apple App Store и Google Play Store; данное уведомление применяется везде, где включены push-уведомления, и предоставляется на языке пользователя, если поддерживается.

## 1. НА ЧТО ВЫ ДАЁТЕ РАЗРЕШЕНИЕ

Если вы нажмёте **«Разрешить»** в следующем окне, `Civo Cloud Manager` сможет:

- отправлять уведомления на ваше устройство
- показывать оповещения, значки, баннеры и звуки (в соответствии с настройками вашей ОС)
- использовать APNs Apple / FCM Google как канал доставки (токен push вашего устройства передаётся этим провайдерам только для доставки)

---

## 2. О ЧЁМ БУДУТ УВЕДОМЛЕНИЯ

`Civo Cloud Manager` отправляет уведомления по следующим причинам:

| Категория | Примеры | По умолчанию |
|---|---|---|
| **Сервисные уведомления** (важные) | оповещения по аккаунту, предупреждения о безопасности, напоминания об оплате, важные обновления | Вкл. |
| **Транзакционные** | подтверждение ваших действий, изменения статуса по вашему запросу | Вкл. |
| **Напоминания** | напоминания, которые вы сами настроили в `Civo Cloud Manager` | По вашему выбору |
| **Советы и новые функции** | периодические обновления о новых возможностях | Выкл. по умолчанию — требуется согласие |
| **Маркетинг / промо** | предложения, акции, новости о новых продуктах | Выкл. по умолчанию — требуется отдельное согласие по § 4 |

Каждую категорию можно включить или отключить отдельно в **Настройки → Уведомления** внутри `Civo Cloud Manager` — и в любой момент в системных настройках уведомлений вашего устройства.

## 3. ОТСУТСТВИЕ ОТСЛЕЖИВАНИЯ ЧЕРЕЗ УВЕДОМЛЕНИЯ

Мы **не**:

- используем уведомления для отслеживания вашего местоположения
- включаем в ваши уведомления персональные данные других пользователей
- используем тихие / фоновые уведомления для сбора аналитики о вас
- передаём токен push вашего устройства третьим лицам, кроме Apple / Google, для доставки

---

## 4. МАРКЕТИНГОВЫЕ УВЕДОМЛЕНИЯ

Маркетинговые / промо push-уведомления регулируются ст. 6(1)(a) GDPR + ePrivacy ст. 13: **требуется явное, отдельное, детализированное согласие**.

- Переключатель маркетинга **выключен** по умолчанию
- Вы можете включить (и выключить) его в любое время в **Настройки → Уведомления → Маркетинг**
- Согласие на push-маркетинг **отдельно** от согласия на email-маркетинг; включение одного не включает другое
- Отзыв согласия так же прост, как и его предоставление (один переключатель), и не влияет на немаркетинговые уведомления

## 6. ПРИВЛЕКАЕМЫЕ СУБПРОЦЕССОРЫ

Доставка push-уведомлений осуществляется с помощью нативных сервисов платформы:

- **Apple Push Notification service (APNs)** — Apple Distribution International Ltd. (независимый оператор для канала доставки)
- **Firebase Cloud Messaging (FCM) / Google Mobile Services** — Google Ireland Limited (независимый оператор для канала доставки)

Они выступают самостоятельными операторами для уровня доставки в соответствии со своими политиками конфиденциальности. См. [`processors/apple.md`](processors/apple.md) и [реестр субпроцессоров Google Cloud](processors/google-cloud.md).

## 7. ВАШИ ПРАВА

Вы можете в любое время:

- **Отключить** все уведомления на уровне ОС (Настройки → Уведомления → `Civo Cloud Manager` → выкл.)
- **Отключить отдельные категории** в приложении (Настройки → Уведомления)
- **Отозвать согласие на маркетинг** без потери сервисных уведомлений
- **Запросить удаление** любых данных, связанных с предпочтениями уведомлений, через  `data-protection@digitalfreedom.co.za` 

Отзыв согласия не влияет на законность обработки до момента отзыва.

## 8. ЕСЛИ ВЫ ВЫБЕРЕТЕ «НЕ РАЗРЕШАТЬ»

Если вы отклоните системный запрос:

- `Civo Cloud Manager` продолжит работать — ни одна функция не ограничена разрешением на уведомления
- вы можете изменить решение позже в **Настройки → Уведомления → `Civo Cloud Manager`** (на уровне ОС)
- мы не будем повторно запрашивать разрешение или использовать манипулятивные методы для получения согласия
