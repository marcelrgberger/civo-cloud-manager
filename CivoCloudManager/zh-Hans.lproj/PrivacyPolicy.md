## 1. 引言

本隐私政策说明，当您使用我们的应用程序、软件、网站及相关服务（“服务”）时，DigitalFreedom（DigitalFreedom Global LLC 旗下品牌，合称“我们”）如何收集、使用、存储和保护您的个人数据。本文本适用于 macOS 应用 Civo Cloud Manager（“本应用”）。

### 1.1 全球适用范围

本应用通过 Apple App Store 分发，因此在 App Store 服务的每一个国家和地区均可获取。无论本应用在哪个国家下载、访问或使用，本隐私政策均全球适用于本应用的所有用户。

### 1.2 以 GDPR 作为全球基准

我们采用**欧盟通用数据保护条例（GDPR）**及相关欧盟数据保护法律作为基准，并将其作为**全球最低标准**——每位用户，无论身处何国，均至少享有本政策所规定的 GDPR 级别的保护。我们还尊重并遵守用户所在司法辖区的任何适用的本地数据保护法律；如该本地法律对用户的保护更为充分，则适用更高的保护标准。

我们致力于保护您的隐私并遵守适用的数据保护法律，包括但不限于：

- 欧盟通用数据保护条例（GDPR）——作为全球基准适用
- 德国联邦数据保护法（BDSG）
- 英国通用数据保护条例（UK GDPR）及《2018年数据保护法》
- 瑞士联邦数据保护法（FADP）
- 加利福尼亚消费者隐私法案（CCPA）/加利福尼亚隐私权法案（CPRA）及其他美国各州隐私法
- 加拿大个人信息保护与电子文件法案（PIPEDA）
- 澳大利亚《1988年隐私法》
- 巴西通用数据保护法（LGPD）
- 日本个人信息保护法（APPI）
- 韩国个人信息保护法（PIPA）
- 印度数字个人数据保护法（DPDP 法案）及 IT 法案
- 南非个人信息保护法（POPIA）
- 服务通过 Apple App Store 提供的司法辖区内所有其他适用的国家数据保护制度

### 1.3 本应用如何处理您的数据

Civo Cloud Manager 让您在 Mac 上管理您的 Civo 云账户。本应用没有用户账户，没有分析，没有崩溃报告，没有广告，也没有追踪。

- 发布方不运营任何后端来接收您通过本应用的云管理功能所管理的数据。您的 Civo API 密钥、本应用的设置以及您的请求内容保留在您的 Mac 上，或发送给您通过使用本应用所选定的接收方（第 6.1 节）。

## 3. 我们收集的数据

### 3.1 您提供的数据

- **支持请求。** 当您使用“支持”标签页时，支持门户仅收集您输入的内容：您的姓名、电子邮件地址和问题描述。它还会收到您消息的主题、任何附件以及您选择提供给我们的任何账户背景信息。如果您使用单独的途径报告安全漏洞，它会收到漏洞的详细信息和您的联系方式。我们仅将这些数据用于处理您的请求。
- **云管理数据。** 您的 Civo API 密钥、您在本应用中所作的设置以及您所管理的资源，均不会提供给我们。它们保留在您的 Mac 上，或发送给第 6.1 节所述的接收方。

### 3.2 自动收集的数据

- **“支持”标签页。** 使用门户时，其网络服务器会记录您的 IP 地址、时间、所请求的页面、来源页面以及您浏览器的用户代理。门户设置一个会话 Cookie，用于在您填写表单时保障表单安全；该 Cookie 在两小时后过期。您输入时，您的姓名、电子邮件地址和消息的草稿可能会保存在您设备上嵌入式浏览器的本地存储中；发送表单后即被删除。
- **存储在您的 Mac 上、我们不会收到的数据。** 您的 Civo API 密钥（macOS 钥匙串）；已保存的实例凭据（本机的数据保护钥匙串，不同步，读取时需要用户在场）；加密的 SSH 密钥备份及其主密钥（应用支持文件夹和钥匙串）；所选区域、受管防火墙设置、IP 预设、登录时启动和引导设置以及七天试用的开始日期（用户默认设置）；定时防火墙关闭规则以及已结束月份账单金额的缓存（应用支持文件夹）；以及您在本应用中操作的活动日志（资源类型、名称、标识符、操作和简短说明；不含密钥、标头或原始应答）。活动日志保留最新的 200 条记录并丢弃更早的记录；它保留在您的 Mac 上，直至您删除本应用的数据。
- **系统日志。** 本应用写入 macOS 的统一日志。这些条目由操作系统管理，本应用不会上传。

### 3.3 应您的指示与第三方交换的数据

- **Civo。** 本应用向 Civo API（api.civo.com）发送请求（包括作为身份验证的您的 Civo API 密钥），并就实例控制台向 Civo 控制台主机发送请求。这些请求直接到达 Civo，而非我们。
- **您自己的端点。** 本应用连接到您集群的 kubeconfig 中所指定的 Kubernetes API 服务器（使用其中的客户端证书），并使用访问密钥和私密密钥连接到您的对象存储的 S3 兼容端点。本应用本身不保存 kubeconfig 凭据。
- **公共 IP 查询。** 对于防火墙功能，本应用依次向 ipify（api.ipify.org）、ifconfig.me 和 icanhazip.com 查询您的公共 IP 地址，按此顺序作为后备。这些服务与任何网络服务器一样，会看到您的 IP 地址。
- **Apple。** 您对 Full Access 的购买和七天试用权益由 Apple 通过 StoreKit 处理。我们不会收到任何支付数据。对于这些数据，适用 Apple 自己的隐私政策（第 6.1.2 节）。
- **链接。** 指向网站（例如 digitalfreedom.co.za 或 civo.com）的链接会在您的浏览器中打开。

### 3.4 传感器、设备与生物识别数据

- **用户在场（Face ID / Touch ID / 密码）：** 用于解锁已保存的凭据。生物识别模板绝不会离开您的设备。本应用仅从操作系统接收是/否结果。
- **通知：** 本应用向 macOS 请求显示提醒和播放声音的权限，并在您的 Mac 上本地安排通知。它不注册推送令牌，也不接收远程通知。
- **您选择的文件：** 您导出的 SSH 私钥、kubeconfig 文件和对象存储下载内容，会写入您在系统文件对话框中选择的位置。这些副本处于本应用的保护和管理范围之外；本应用不会跟踪、加密或删除它们。

### 3.5 不收集的数据

本应用**不会**收集或使用：

- 位置、相机、麦克风、联系人、日历、照片或健康数据
- 分析、崩溃报告或遥测数据
- 广告标识符，或任何用于在其他公司的应用和网站之间追踪您的数据
- 支付卡数据（款项由 Apple 收取；我们从不接收银行卡详细信息）

我们仅在为本政策所述目的所必需的期间内保留个人数据。

**支持请求：**

## 9. 数据安全

本应用采取以下措施：

- 您的 Civo API 密钥存储在 macOS 钥匙串中。已保存的实例凭据存储在本机的数据保护钥匙串中，不同步，读取时需要用户在场。SSH 密钥备份以加密方式存储，其主密钥位于钥匙串中。
- 对 Civo API 的请求使用 HTTPS。
- 本应用在启用 Hardened Runtime 的 macOS App Sandbox 中运行。
- 本应用不含遥测。
- 您导出的文件不受本应用保护（第 3.4 节）。

对于支持门户：连接已加密（TLS），会话 Cookie 仅通过加密连接发送且脚本无法读取，对工单的访问仅限于答复工单的人员。

没有任何系统是绝对安全的。我们无法保证数据的绝对安全。

### 9.1 向您发出的违规通知

如发生**可能对您的权利和自由造成高风险**的个人数据泄露事件（Art. 34 GDPR），我们将使用您在支持请求中提供的联系方式，在不无故拖延的情况下通知您，内容包括：

- 泄露的性质
- 涉及的记录类别及大致数量
- 可能产生的后果
- 已采取或拟采取的应对泄露及减轻不利影响的措施
- 获取更多信息的联系方式

如单独通知需付出不成比例的努力，我们将在 https://digitalfreedom.co.za/. 发布公开公告。

无论您居住在何处，您至少可以行使：

- **限制**处理（Art. 18）

- **14 岁以下：** 处理儿童的数据需要法定代理人的同意，且仅收集核实该同意所需的最少信息。本应用不面向儿童。
- **答复期限：** 对访问、更正/删除和暂停处理的请求，在 **10 天**内处理，否则会告知您原因和时间安排。这比 GDPR 的一个月更短，以较短期限为准。
- **泄露：** 将不无故拖延地通知您；超过法定规模的，在 **72 小时**内通知个人信息保护委员会或指定机构。

### 17.11 土耳其（KVKK）

- KVKK（Law No. 6698）在概念上与 GDPR 相似，但更侧重于以明示同意作为一般依据；每项处理活动均单独依据土耳其法律进行评估，而不是假定可沿用 Art. 6(1)(f) 的分析。
- **向境外转移：** 除“支持”标签页外，本应用不会向我们传输任何个人数据。支持请求在何处处理，见 § 7。
- **答复期限：** 请求在 **30 天**内答复。在先向我们申请之后——于我们答复后 30 天内或您申请后 60 天内——您可以向个人数据保护委员会（Kişisel Verileri Koruma Kurulu，Art. 14 KVKK）投诉。

### 17.12 南非（POPIA）

POPIA § 3(1) 适用于住所位于共和国境内的责任方，或通过位于该国境内的手段进行的处理。这两种情形均不存在——控制者的住所位于怀俄明州，在法兰克福和伦敦的服务器上处理，并在欧盟的 Storj 存储节点上另有一份提供商之外的备份副本（§ 7），而 `.co.za` 域名只是一个名称，不是处理手段。**因此，根据目前的事实，该法不适用。** 尽管如此，每一项 POPIA 类的询问，仍通过与其他地方相同的渠道并按相同的时限答复——这是一项服务承诺，而非承认该法适用。POPIA 与 GDPR 最低标准有所不同的两点，在此明确说明而不加掩饰：POPIA 将所有 18 岁以下的人视为儿童，且 § 22(1) 要求的违规通知没有 GDPR 的高风险门槛——违规计划按 GDPR 标准运作。信息监管机构：JD House，27 Stiemens Street，Braamfontein，Johannesburg，2001 — <https://inforegulator.org.za>。
